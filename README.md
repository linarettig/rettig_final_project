# R Adventures — course portfolio

Quarto website for **R Adventures: A Data Traveler’s Journey** (environmental data science / R coursework).

## Live site

After you enable **GitHub Pages** (Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **master**, Folder: **/docs**) and push a rendered `docs/` folder, the site is usually available at:

**https://linarettig.github.io/rettig_final_project/**

If your Pages URL is different (custom domain or `main` branch), replace the link above in this README.

## Local preview

```bash
quarto preview
```

## Build for publishing

```bash
quarto render
```

Then commit and push the updated `docs/` directory so GitHub Pages can serve the new HTML.
