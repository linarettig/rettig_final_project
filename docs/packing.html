Trail routines (checklists)

Wrangling

  • Import → inspect (glimpse, summary)
  • Fix types + names
  • Document missingness
  • Filter → mutate → summarise
  • Save + commit when it runs

Visualization

  • Start with one geom
  • Add encodings next
  • Facet if needed
  • Labels + units + caption
  • Export the right size (slides vs report)

Analysis

  • Plot before you “math”
  • State the question + null (if testing)
  • Check assumptions / diagnostics
  • Write the takeaway in English first

Emergency kit (fast fixes)

  • object not found: spelling + ls() + “did I run the chunk above?”
  • Join exploded rows: check duplicate keys with count(id, sort = TRUE)
  • Forgotten package: library() / install once, then restart if needed

Travel wisdom (hard-won)

TipLessons that survived contact with reality
  1. Small rep first — if it doesn’t work tiny, it won’t work huge.
  2. Commit when it runs — future you sends thanks.
  3. Plot early — your eyes are a model too.
  4. Read the error from the top — it’s usually honest.
  5. Celebrate working chunks — progress is cumulative.
